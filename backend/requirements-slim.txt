# FLUX Backend — slim dependency set for 512 MB hosts (Render free tier).
#
# Identical to requirements.txt minus torch, transformers and chronos-forecasting.
# Measured resident memory after importing everything here: ~248 MB, against
# ~748 MB for the full set. torch alone accounts for 445 MB of that gap, which
# is why it goes and everything else stays.
#
# What this costs, and nothing else:
#   • FinBERT/CryptoBERT news sentiment  → replaced by SENTIMENT_BACKEND=llm,
#     which scores the same headlines with the configured chat model.
#   • The LSTM magnitude head (magnitude.py) → the XGBoost direction
#     classifier and the conformal bands are unaffected.
#   • The Chronos zero-shot baseline (baselines.py) → a benchmark to beat,
#     not a serving path; the ARIMA baseline still runs.
#
# Every one of those imports torch lazily inside a function and is already
# wrapped in try/except, so their absence degrades the feature rather than
# breaking the app. Chroma/RAG is NOT dropped — it costs 16 MB.
#
# Install:  pip install -r backend/requirements-slim.txt
